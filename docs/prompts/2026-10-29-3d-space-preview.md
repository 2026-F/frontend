# 내 공간에 걸어보기 3D 전환

- 작성일: 2026-10-29
- 관련 이슈 / PR: 이슈 미확인, PR 생성 전

## 목적

내 공간에 걸어보기가 작품 2D 사진을 카메라 위에 붙이는 방식이었다. 3D 뷰어와 공간 미리보기가 따로 있었다.
3D 작품 모델을 카메라 화면이나 불러온 사진 위에 띄워 배치하도록 합친다.
제약: 실제 공간 인식(AR)은 하지 않는다. 크기와 위치는 사용자가 맞춘다.

## 핵심 요청

> 지금 문제가 잇거든 카메라에는 3d가 아닌 작품 2d사진이 들어가는데 그걸 원하는게 아니라 3d작품 배경을 카메라로 하거나 아니면 가져온 이미지를 넣어서 내공간에 넣어보기를 하고 싶은건데 지금은 그 두개가 나뉘어있어 2d사진 은 없애도 됨

## 선택과 이유

| 검토한 방법 | 선택 | 이유 |
| --- | --- | --- |
| 2D 사진 배치 제거 | 채택 (사용자 요청) | 요청 원문 |
| 투명 배경 model-viewer를 카메라 video, 사진 img 위에 겹침 | 채택 (AI 결정) | 3D 뷰어와 같은 모델과 텍스처를 그대로 사용. 의존성 추가 없음 |
| model-viewer AR 모드 | 제외 (AI 판단) | 기기별 지원 차이가 크고 카메라 화면 위 사진 합성 흐름과 맞지 않음 |
| 조작: model-viewer 기본 제스처 (한 손가락 회전, 두 손가락 이동, 핀치 크기) | 채택 (AI 결정) | 직접 제스처를 구현하지 않아도 회전까지 지원 |
| 크기 슬라이더: 카메라 거리 조절, 최대 거리 4배 허용 | 채택 (AI 결정) | model-viewer 기본값은 처음 거리보다 멀어질 수 없어 작게 줄일 수 없음 |
| 셔터: 배경 프레임 + toBlob(PNG, 투명) 합성 후 JPEG | 채택 (AI 결정) | 화면에 보이는 그대로 저장. 기존 저장 함수 재사용 |
| 모델 결정 규칙 공용화 (전용 모델, 캔버스 + 사진, 샘플) | 채택 (AI 결정) | 3D 뷰어와 공간 미리보기 결과를 같게 유지. 공간 미리보기는 샘플 모델 제외 |
| 걸어보기 버튼 조건: 사진 유무에서 3D 가능 여부로 변경 | 채택 (AI 결정) | 모델이 없는 입체 작품은 배치할 수 없음 |

## 반영 내용

- `lib/artworkModel.ts`: 모델 소스 결정, 미디어 API 모델 조회, 3D 노출 조건
- `components/artwork-model/ArtworkModelViewer.tsx`: model-viewer 래퍼, 캔버스 텍스처 적용, 투명 배경
- `components/space-preview/Live3DPlacement.tsx`: 카메라/사진 배경 전환, 3D 겹치기, 크기 슬라이더, 처음 위치로, 셔터와 저장
- `SpacePreview`, 미리보기 페이지: 작품 정보를 넘겨 3D 모델로 배치. 모델이 없으면 안내 문구
- 삭제: `LiveArtworkPlacement`, `WallPhotoPicker`, `composePlacement`, `loadImageForCanvas`
- `lib/composeImage.ts`: `composeLayers` 추가
- 3D 뷰어 페이지: 공용 모듈 사용, 걸어보기 링크 추가
- 작품 상세: 걸어보기 버튼을 3D 가능 작품에만 노출

## 검증

| 확인 항목 | 방법 | 결과 |
| --- | --- | --- |
| 타입, 린트, 빌드 | `npx tsc --noEmit`, `npm run lint`, `npm run build` | 통과. 린트는 기존과 같은 `<img>` 경고만 |
| 카메라 배경 + 3D | Playwright Chromium 가짜 카메라, 목데이터 작품 1 | 카메라 화면 위에 캔버스 모델 표시, 텍스처 적용 |
| 투명 렌더 | toBlob PNG 픽셀 확인 | 모서리 알파 0, 중앙 작품 색 |
| 회전, 크기, 셔터 | 드래그, 슬라이더, 셔터 | 회전과 축소 반영, 배경과 3D가 합쳐진 결과 미리보기 |
| 사진 배경 | 파일 선택으로 벽 사진 업로드 | 카메라 꺼지고 사진 위에 모델 표시 |
| 카메라 없음 | 가짜 카메라 없이 실행 | 오류 문구와 사진으로 걸어보기 버튼 표시 |
| 3D 뷰어 링크 | 뷰어 페이지 | 걸어보기 링크 표시 |

미검증: 실기기(iOS Safari, Android Chrome) 터치 제스처와 저장, 실제 API 작품과 S3 이미지(CORS) 텍스처, 전용 3D 모델(MODEL_3D) 작품.
