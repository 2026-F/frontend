# 마감된 경매 일괄 다시 열기와 날짜 지정

- 작성일: 2026-11-05
- 관련 이슈 / PR: 미생성. 후속 작업 대상: [BE #107](https://github.com/2026-F/Artbid/pull/107), [FE #61](https://github.com/2026-F/frontend/pull/61)
- 브랜치: FE `feature/auction/bulk-reopen` (develop 기준)
- 이전 기록: 백엔드 저장소 `docs/prompts/2026-11-05-auction-reopen.md`

## 목적

시연 전에 마감된 작품을 한 번에 다시 열고, 진행 기간을 분이 아닌 날짜로 1~2주 정도 지정한다.

## 핵심 요청

> 그 전체 선택해서 다시열기 버튼 만들어주고, 60분이 아니라 길게 1주 2주정도로 설정하고 싶어서 날짜로 설정할 수 있게 해줘

## 선택과 이유

| 검토한 방법 | 선택 | 이유 |
| --- | --- | --- |
| 고른 날짜를 브라우저에서 남은 분으로 바꿔 기존 API 호출 | 채택 | 백엔드가 이미 30일까지 받아 API 변경이 없다. 간격으로 보내므로 서버와 브라우저의 시간대 차이에 영향받지 않는다 |
| 기존 API를 작품별로 순서대로 호출 | 채택 | 작품별 성공과 실패를 그대로 보여줄 수 있다. 일괄 API는 만들지 않았다 |
| 실패해도 나머지를 계속 진행 | 채택 | 결제 완료 건은 서버가 409로 거절하므로 전체 선택 시 일부 실패가 정상 경로다 |
| 일괄 실행 전 확인창 표시 | 채택 | 미결제 낙찰이 무효가 되고 되돌릴 수 없다. AI 판단이다 |

## 반영 내용

1. `components/ReopenEndPicker.tsx`: 날짜 입력, 1주와 2주 버튼, 날짜를 분으로 바꾸는 함수. 기본값은 지금부터 7일 뒤다.
2. `components/AdminArtworkRow.tsx`: 분 입력을 날짜 입력으로 교체. 다시 열 수 있는 작품에 선택 체크박스 추가.
3. `app/admin/page.tsx`: 전체 선택, 일괄 다시 열기, 결과와 실패 목록 표시. 행 key에 경매 ID를 포함해 재오픈 후 행 상태를 초기화한다.

## 검증

| 확인 항목 | 방법 | 결과 |
| --- | --- | --- |
| 정적 검사 | `npx tsc --noEmit`, `npm run lint`, `npm run build` | 통과. 변경 파일에 lint 오류 없음 |
| 전체 선택 | 로컬 FE, BE와 헤드리스 Chrome | 0/33, 33/33, 0/33 전환. 선택 없으면 버튼 비활성화 |
| 범위 밖 날짜 | 같은 환경에서 과거와 30일 초과 입력 | 안내 문구 표시, API 호출 없음 |
| 일괄 다시 열기 | 2주 버튼으로 유찰 2건과 결제 완료 1건 실행 | 2건 200, 1건 409. 실패 목록에 작품명과 사유 표시 |
| 개별 다시 열기 | 1주 버튼으로 1건 실행 | 200, 체크박스 사라짐 |
| 마감 시각 | 로컬 DB 조회 | 새 경매 ONGOING, 2주와 1주 뒤로 저장 |
| 좁은 화면 | 390px 스크린샷 | 가로 스크롤 없음 |

전체 선택 후 실행은 로컬의 기존 데이터를 바꾸므로 하지 않았다. 선택 해제까지만 확인했고 실행은 3건을 골라 확인했다.

미검증:
- 운영 서버에서 실행하지 않았다.
- 서버가 UTC로 동작할 때의 화면 표시는 확인하지 않았다. 마감 시각 저장이 시간대 없는 값이라 표시와 카운트다운이 9시간 어긋날 수 있다.

## 남은 작업

- 관리자 화면은 상태별 100개까지만 불러오므로 전체 선택 범위도 그 안이다.
- 로그인 상태의 홈 화면에서 hydration 오류가 난다. 이번에 바꾸지 않은 화면이며 원인은 미확인이다.
