# MY 구매자 주문 및 배송 현황

- 작성일 2026-11-25
- 관련 이슈 [frontend #90](https://github.com/2026-F/frontend/issues/90)

## 목적

구매자가 MY에서 본인의 낙찰 주문을 확인하고 배송지를 저장하거나 운송장을 조회한다.

## 핵심 요청

요약. 개발계획서는 우선순위와 기능 범위를 확인하는 자료로 사용한다. 발행된 프론트엔드 이슈에서 첫 구현 대상을 선정하고, 한 이슈의 구현과 검증을 진행한다.

## 선택과 이유

| 검토한 방법 | 선택 | 이유 |
| --- | --- | --- |
| #90 구매자 주문 및 배송 | 채택 | 기존 정산·배송 API로 시작할 수 있고 #92 결제 연결과 #98 컬렉션에 주문 상세 경로를 제공한다. |
| #92 결제 복구부터 구현 | 보류 | #90 주문 화면과 [백엔드 결제 복구 계약](https://github.com/2026-F/Artbid/issues/145)에 의존한다. |
| 회원 ID와 토큰으로 주문 화면 상태를 분리 | 채택 | 계정과 세션이 전환되면 조회 결과와 입력을 즉시 초기화한다. 요청마다 시작 시점의 토큰을 고정하고 이탈 시 요청을 취소하며, 응답 반영 전에 현재 세션을 다시 확인한다. |
| 응답의 결제 기한을 문자열로 표시 | 채택 | 오프셋 없는 서버 응답을 브라우저 시간으로 재해석하는 일을 피한다. 기한에 따른 결제 가능 여부는 #92에서 서버 기준으로 다룬다. |

위 선택은 Codex 판단이다. 작업 기준은 프론트엔드 `develop`의 `164b39d`, API 대조 기준은 백엔드 `main`의 `1bf2266`이다.

## 반영 내용

- MY에서 주문 목록과 상세로 이동한다. 목록과 상세에 낙찰자, 결제 상태, 금액 및 결제 기한을 확인하는 흐름을 연결했다. 경매 상세 조회에 실패하면 경매 번호를 표시하고 주문 정보와 상세 링크를 유지한다.
- 배송지 미등록, 발송 대기, 발송 완료를 구분한다. 배송지 입력 검증, 저장 실패 시 입력 유지, 발송 충돌 시 재조회, 운송장 읽기 전용 표시를 추가했다.

## 검증

| 확인 항목 | 방법 | 결과 |
| --- | --- | --- |
| 정적 검사 | `npm run lint`, `npx tsc --noEmit`, `npm run build` | 통과. 기존 이미지·폰트 관련 ESLint 경고가 출력된다. |
| 로컬 API 연동 | 백엔드 `1bf2266`에서 생성한 격리 환경과 390px Chrome | 구매자 로그인, MY 진입, 정산·경매 정보, 배송지 GET·PUT, 판매자 운송장 등록, 저장 409 후 최신 운송장 표시를 확인했다. 401·403·배송지 미등록 404, 관계없는 회원과 작품 판매자의 구매자 화면 접근 거절을 확인했다. |
| 오류·세션 전환 | Chrome에서 응답을 제어해 재현 | 빈 목록, 작품 조회 실패, 주소 검증, 조회 재시도, 저장 실패 시 입력 유지, 만료 안내와 계정 변경 이전의 지연된 목록·배송 조회·저장 응답 미반영을 확인했다. |

로컬 연동에서는 테스트 정산을 DB에 준비하고 결제 완료 상태를 설정했다. 토스 결제, 운영 배포 화면과 실기기 검증은 [통합 검증 이슈 #105](https://github.com/2026-F/frontend/issues/105)에서 확인한다.

## 2026-11-25 PR #106 리뷰 후속

[리뷰 코멘트](https://github.com/2026-F/frontend/pull/106#issuecomment-7156973522)의 탭 간 계정 전환과 주문 만료 후 배송지 편집 상태를 수정한다.

- 주문 화면에서 공유 브라우저 저장소의 로그인 변경을 감지한다. 현재 탭의 회원·토큰 정보가 공유 토큰과 일치할 때만 주문 화면과 응답을 반영한다.
- 배송지 저장이 `SETTLEMENT_NOT_SHIPPABLE`로 거절되면 저장을 잠그고 정산을 다시 조회한다. 조회 실패 시 상태 조회를 다시 시도할 수 있게 하고, 만료가 확인되면 주소를 읽기 전용으로 표시한다.

| 확인 항목 | 방법 | 결과 |
| --- | --- | --- |
| 정적 검사 | `npm run lint`, `tsc --noEmit`, `npm run build` | 통과. 기존 린트 경고와 빌드 중 외부 폰트 다운로드 경고가 출력된다. |
| 탭 간 세션 변경 | 로컬 목업 API와 브라우저 탭 2개 | 다른 탭에서 로그아웃하면 배송지 폼이 사라진다. 타인 계정에는 접근 거절을 표시하고, 원래 계정으로 재로그인해도 이전 미저장 입력이 복원되지 않는다. |
| 주문 만료 충돌 | 로컬 목업 API와 브라우저 | 저장 409 후 정산을 다시 조회해 결제 기한 만료를 표시하고, 저장 버튼을 숨기며 등록된 주소를 유지한다. |

후속 검증은 목업 API를 사용했다.
