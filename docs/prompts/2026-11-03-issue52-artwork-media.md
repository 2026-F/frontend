# FE #52 작품 3D와 공간 미리보기

- 작성일: 2026-11-03
- 관련 이슈: [FE #52](https://github.com/2026-F/frontend/issues/52)

## 목적

작품 3D와 공간 미리보기에서 실제 작품에 연결된 미디어만 표시한다.

## 핵심 요청

요약: 샘플 작품·모델 자동 대체를 제거하면서 실제 작품 사진을 평면 모델에 적용하는 기능은 유지한다. 사용자는 프론트 작업을 세 PR로 나누고, 마지막 프롬프트 기록도 앞의 기록을 포함하지 않는 별도 기록으로 작성하도록 요청했다.

## 선택과 이유

| 방법 | 선택 | 이유 |
| --- | --- | --- |
| 작품 전용 3D 모델 사용 | 채택 | 작품에 등록된 모델을 그대로 보여준다. |
| 평면 작품의 실제 사진을 캔버스 모델에 적용 | 채택 | 전용 모델이 없어도 실제 작품 사진으로 미리볼 수 있다. |
| 샘플 모델로 자동 대체 | 제외 | 미디어가 없거나 조회에 실패한 상황을 숨기지 않는다. |

## 반영 내용

작품 상세 미디어를 기준으로 모델을 결정한다. 이미지나 모델이 없으면 안내하고, 모델이나 텍스처 로드 실패는 오류로 표시한다. 개발 데이터 도구가 생성하는 로컬 작품에서 사용할 SVG 이미지도 추가한다.

## 검증

| 확인 항목 | 방법 | 결과 |
| --- | --- | --- |
| 빌드 | `frontend/`에서 `next build` | 성공. 이미지·폰트 lint 경고가 남았다. |
| 평면 모델 | 실제 로컬 API와 브라우저 | 실제 작품 사진이 캔버스에 적용된 화면을 확인했다. |
| 미디어 없음 | 실제 로컬 API와 브라우저 | 이미지 없는 작품에서 샘플 대신 미디어 없음 안내를 확인했다. |

위 브라우저 검증은 PR 분리 전 동일한 최종 구현에서 수행했다. 실제 미디어 업로드, 모바일 실기기, 카메라 권한과 사진 합성 저장은 확인하지 않았다.

## 남은 작업

배포 후 실제 이미지 URL과 외부 이미지 CORS, 모바일 카메라 동작을 확인한다.
