# FE #52 작품 3D와 공간 미리보기

- 작성일: 2026-11-03
- 관련 이슈: [FE #52](https://github.com/2026-F/frontend/issues/52)

## 목적

작품 3D와 공간 미리보기에서 실제 작품에 연결된 미디어만 표시한다.

## 핵심 요청

요약: 원래 이슈 [FE #52](https://github.com/2026-F/frontend/issues/52)와 해당 PR의 작업 범위를 대조해 정리했다. 사용자 프롬프트 원문 인용이 아니다.

- 작품 상세·3D 뷰어·공간 미리보기에서 운영 목데이터와 샘플 작품·모델 자동 대체를 제거한다. 실제 작품에 연결된 미디어를 사용한다.
- 작품 전용 3D 모델이 있으면 해당 모델을 사용한다. 전용 모델이 없는 평면 작품은 실제 작품 사진을 캔버스 모델에 적용하는 기존 미리보기 흐름을 유지한다.
- 이미지나 모델이 없으면 미디어 없음 안내를 표시하고, 작품 조회나 모델·텍스처 로드가 실패하면 오류를 드러낸다. 다른 샘플 작품으로 정상 표시된 것처럼 보이게 하지 않는다.
- 기존 3D·공간 미리보기의 정상 데이터 흐름을 유지하고 실제 작품 사진과 미디어 없는 작품을 각각 확인한다. 기존 UI 전체 재작성은 범위에 포함하지 않는다.

### 작업 분리 배경

FE #52를 세 PR로 나누고 기록을 각각 작성하라는 후속 요청에 따라, 이 PR은 #56의 실제 작품 조회를 바탕으로 3D·공간 미리보기의 미디어 처리를 담당한다. 앞선 PR의 전체 기록을 반복하지 않는다.

## 선택과 이유

| 방법 | 선택 | 이유 |
| --- | --- | --- |
| 작품 전용 3D 모델 사용 | 채택 | 작품에 등록된 모델을 그대로 보여준다. |
| 평면 작품의 실제 사진을 캔버스 모델에 적용 | 채택 | 전용 모델이 없어도 실제 작품 사진으로 미리볼 수 있다. |
| 샘플 모델로 자동 대체 | 제외 | 미디어가 없거나 조회에 실패한 상황을 숨기지 않는다. |

## 반영 내용

작품 상세 미디어를 기준으로 모델을 결정한다. 이미지나 모델이 없으면 안내하고, 모델이나 텍스처 로드 실패는 오류로 표시한다. 개발 데이터 도구가 생성하는 로컬 작품에서 사용할 SVG 이미지도 추가한다.

## 검증

| 확인 항목 | 방법 | 결과 |
| --- | --- | --- |
| 빌드 | `frontend/`에서 `next build` | 성공. 이미지·폰트 lint 경고가 남았다. |
| 평면 모델 | 실제 로컬 API와 브라우저 | 실제 작품 사진이 캔버스에 적용된 화면을 확인했다. |
| 미디어 없음 | 실제 로컬 API와 브라우저 | 이미지 없는 작품에서 샘플 대신 미디어 없음 안내를 확인했다. |

위 브라우저 검증은 PR 분리 전 동일한 최종 구현에서 수행했다. 실제 미디어 업로드, 모바일 실기기, 카메라 권한과 사진 합성 저장은 확인하지 않았다.
